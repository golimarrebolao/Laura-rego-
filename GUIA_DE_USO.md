# 📘 Guia rápido de uso e organização

Este guia explica como navegar pelo repositório **Laura-rego-** e como manter a coleção organizada, mesmo se você estiver começando a usar o GitHub.

## 🧭 1. Como navegar

1. Volte ao [README principal](./README.md).
2. Escolha a categoria que parece combinar com o que você procura.
3. Abra o arquivo indicado.
4. Leia o título e a descrição da seção.
5. Clique no nome do recurso para visitar o site.

## 🗂️ 2. Como entender os arquivos

| Arquivo | Conteúdo |
|---|---|
| `Melhores IAs 🤖.md` | Ferramentas de IA, estudo e pesquisa. |
| `Pesquisa e privacidade.md` | Buscadores e serviços relacionados à privacidade. |
| `Sites divertidos🎮.md` | Jogos, experiências e links agrupados por nome. |
| `Scripts🔗.md` | Exemplos de código e atalhos de navegador. |
| `Sound botton guia📋` | Palavras-chave para pesquisar sons. |

## ✏️ 3. Como editar uma página pelo GitHub

1. Entre no arquivo que deseja alterar.
2. Clique no ícone de lápis (**Edit this file**).
3. Faça a alteração no editor.
4. Use **Preview** para conferir a formatação, se essa opção estiver disponível.
5. Clique em **Commit changes**.
6. Escreva uma mensagem curta explicando a mudança e confirme.

> 💡 Uma mensagem de commit é apenas um resumo do que você alterou, por exemplo: `Adiciona novo jogo à coleção`.

## ➕ 4. Como adicionar um link

Use este formato:

```markdown
- [Nome do recurso](https://exemplo.com/) — descrição curta.
```

Exemplo fictício:

```markdown
- [Meu jogo de exemplo](https://exemplo.com/) — jogo de navegador com fases.
```

Antes de salvar:
- Pesquise o endereço na página para evitar duplicatas.
- Confira se o link está escrito corretamente.
- Coloque-o na seção certa.
- Não invente descrições: se não conhecer o recurso, deixe claro que ele ainda não foi identificado.

## 🧩 5. Como criar uma seção

Se um novo grupo ainda não existir, adicione um título no arquivo:

```markdown
## 🎯 Nome do grupo

Uma frase explicando o que reúne.

- [Nome do link](https://exemplo.com/) — descrição.
```

Use nomes consistentes e mantenha juntos os endereços que pertencem ao mesmo jogo ou serviço.

## 🔍 6. Como encontrar algo rapidamente

- Use **Ctrl + F** no computador para pesquisar uma palavra ou nome na página.
- Procure primeiro pelo nome do jogo ou serviço.
- Se não encontrar, tente uma palavra relacionada.
- Se houver vários endereços na mesma seção, eles podem ser alternativas do mesmo grupo.

## 🛡️ 7. Cuidados básicos

- Confira o domínio antes de abrir um link.
- Não informe senhas ou dados pessoais em páginas desconhecidas.
- Não baixe arquivos sem saber de onde vêm e o que fazem.
- Leia scripts antes de executá-los.
- Um link salvo aqui não foi necessariamente testado ou verificado.

## 🧹 8. Manutenção da coleção

De tempos em tempos:
- Confira links que pararam de funcionar.
- Remova duplicatas somente depois de comparar os endereços.
- Atualize descrições quando tiver certeza do que o recurso faz.
- Não mude o nome de um grupo se isso puder confundir quem já usa a coleção.
